From sources to a lesson

This execution used an LLM-assisted editorial loop and a reproducible static compiler. It did not run an autonomous multi-agent system or a vector database.

1. Public source screening2. Evidence notes / excerpt IDs3. Linked English Wiki4. Claim and rights review5. Approved outline6. Chinese teaching slides7. HTML / browser checks

Revision paths

  • Unsupported historical claim: return to the original source. Remove it or mark uncertainty if support is insufficient.
  • Terminology mismatch: return to the Wiki definition before translating again.
  • Wrong attribution or image rights: reject the asset before layout. Use a permitted substitute or a link.
  • Broken anchor or layout: repair the compiler or navigation, rebuild, then rerun checks.

Stopping conditions

At least five ingested sources, seven content pages, traceable slide references and exactly 18 slides. Structural checks must pass. No known critical navigation failures. After three unsuccessful revisions of a claim, mark it unresolved and request human review rather than inventing an answer. Chinese human review remains a stated limitation.

Reusable retrieval output

sources.json retains stable evidence IDs; wiki.json stores labelled claims. A future Rug Detective retrieval system can consume these files, but must retain the human motif-confirmation step and keep fiction separate.
