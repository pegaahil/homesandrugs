# Persian Rug Motifs

English linked LLM-assisted Wiki and Traditional Chinese and English 18-slide HTML lesson. Open index.html or presentation.html. No install, secret or live API required.

Build: `python scripts/build.py`
Check: `python scripts/check.py`

Read AGENTS.md for editorial rules. data/sources.json contains ten public-source notes; data/wiki.json contains labelled claims; data/slides.json records slide-to-Wiki-to-evidence mapping. Original museum text is not republished. Museum photographs retain their stated rights. Source notes are concise paraphrases. Chinese is unreviewed.
