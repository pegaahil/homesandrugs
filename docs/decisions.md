# Current design

Room Match combines local palette extraction and catalog ranking with an optional manual try-on step. The guided journey is upload, discover reasons, try a rug, and compare two. Preferences and results appear after a room is available; detailed scores stay expandable.

One shared floor quadrilateral makes colour/pattern comparisons consistent. It does not represent physical scale. Catalog crop metadata and an approximate oval mask remove most photo margins. Users control the placement; no paid image generation, room upload, furniture detection or lighting simulation occurs.

AGENTS.md defines catalog extension, matching logic, preview boundaries, privacy and release checks. Earlier prototypes remain in Git history and local folders.
